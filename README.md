# DailyBrief — Daily News & Perspective

An editorial-style news discovery and reader application built with pure HTML, CSS, and vanilla JavaScript.

## Features
- **Zero API Key Required**: Fully functional out of the box with a pre-fed database of realistic news articles covering General, Technology, Business, Science, Health, and Sports.
- **Editorial Typography**: Elegant news layout with `Newsreader` serif headlines, warm paper tones, and responsive columns.
- **Category Switching**: Instantaneous filtering between news categories.
- **Real-Time Search**: Search articles across titles, summaries, and source publications.
- **Bookmark / Reading List**: Save articles to your personal reading list stored in browser `localStorage`.
- **Full Article Modal Reader**: Clean, distraction-free reading experience complete with byline, source attribution, and key takeaways.
- **Offline Resilient**: High-quality Unsplash editorial photography with custom SVG fallback covers.

## Running Locally
Open `index.html` in any browser. No build steps or external API keys needed.
